DeployBar questions, answered.

Quick facts about supported deployment providers, installation, privacy, and how the macOS menu bar monitor works.

What is DeployBar?

DeployBar is a native macOS 13+ menu bar app that monitors cloud deployment status and sends alerts when deployments start, succeed, fail, cancel, or disappear.

Which deployment providers does DeployBar monitor?

Vercel, Railway, Netlify, Render, Cloudflare Pages, Cloudflare Workers, DigitalOcean App Platform, Heroku, Fly.io, GitHub Deployments, and GitLab Deployments.

Can DeployBar monitor multiple deployment providers at once?

Yes. DeployBar normalizes deployments from multiple configured providers and accounts into one menu bar status and one compact popover.

Where does DeployBar store provider API tokens?

Provider tokens stay in macOS Keychain. Non-secret settings stay in a local JSON file, and DeployBar has no hosted credential sync.

Is DeployBar free and open source?

Yes. DeployBar is free and open source under the MIT License, with its complete source code available on GitHub.

How do I install DeployBar on macOS?

Install the signed and notarized app with brew install --cask snapre/tap/deploybar, or download the latest release from GitHub.

Local-first deployment monitoring by design.

DeployBar is a Swift Package with a native SwiftUI and AppKit shell. No Electron runtime, no backend account, no telemetry, and no hosted credential sync.

  • Tokens are stored only in Keychain under the DeployBar token service.
  • Settings are kept under Application Support as local JSON.
  • The app requests notification permission, not Full Disk Access, Accessibility, or Screen Recording.
  • You can build the open-source launch from source with Swift 6 and the included package script.
git clone https://github.com/snapre/DeployBar.git
cd DeployBar
swift test
./Scripts/package_app.sh
open .build/DeployBar.app
